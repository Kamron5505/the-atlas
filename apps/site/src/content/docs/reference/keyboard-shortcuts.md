## Chat kiritish maydoni

| Tugma | Amal |
|---|---|
| `Enter` | Xabarni yuborish yoki tanlangan `/buyruq` ni ishga tushirish |
| `↑` `↓` | Oldingi va keyingi yuborilgan xabarlar |
| `Esc` | Javob kelayotganda: to'xtatish. Aks holda: kiritishni tozalash va tayyor turgan `/compare` ni bekor qilish |
| `Tab` | Tanlangan `/buyruq` yoki `@yo'l` ni to'ldirish |
| `ctrl+r` | Ovoz yozish |
| `ctrl+c` | Chiqish |
| `/` | Buyruqlar menyusini ochish |
| `@` | Fayl, rasm yoki papka biriktirish; yo'l takliflarini ochadi |

`/` yoki `@` menyusi ochiq bo'lganda `↑` `↓` tarix o'rniga menyu bo'ylab harakatlantiradi.

## Ro'yxatlar va tanlash oynalari

Model tanlash, ulash ustasi, tarix, limit menyusi.

| Tugma | Amal |
|---|---|
| Yozish | Filtrlash |
| `↑` `↓` | Harakatlanish |
| `PgUp` `PgDn` | Bir sahifaga siljish |
| `Backspace` | Filtrdan bitta belgini o'chirish |
| `Enter` | Tanlash |
| `Esc` | Orqaga yoki bekor qilish |

## Agentlar oynasi

Ro'yxatlardagi kabi, qo'shimcha ravishda:

| Tugma | Amal |
|---|---|
| `Tab` | "Atlas bepul modellarida ishlatish" ni yoqish/o'chirish |

## OpenRouter'ga kirish

| Tugma | Amal |
|---|---|
| `k` | Brauzer orqali kirish o'rniga kalitni qo'yish |
| `Esc` | Bekor qilish |

## Agent ruxsatlari

| Tugma | Amal |
|---|---|
| `↑` `↓` | Ha / Ha, boshqa so'rama / Yo'q ni tanlash |
| `Enter` | Tasdiqlash |
| `Esc` | Yo'q |

Agent ishlayotganda `Esc` uni to'xtatadi.

## Solishtirish

| Tugma | Amal |
|---|---|
| `←` `→` | Javobni tanlash |
| `Enter` | Uni qoldirish |
| `Esc` | Hech birini qoldirmaslik |

## Ovoz

| Tugma | Amal |
|---|---|
| `Enter` | Yozishni to'xtatish va matnga aylantirish |
| `Esc` | Bekor qilish |
