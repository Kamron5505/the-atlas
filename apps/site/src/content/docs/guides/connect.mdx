## Ulash ustasi

```bash
atlas connect            # pick from a list
atlas connect groq       # go straight to one provider
```

Chatda `/connect` yoki `/connect groq` dan foydalaning.

- **OpenRouter**: bir bosishda kirish. Brauzer OpenRouter'ni ochadi, siz ruxsat berasiz va shaxsiy kalitingiz terminalga o'zi qaytadi. Kalitni qo'lda qo'yish uchun `k` ni bosing.
- **Boshqa bulutli provayderlar**: brauzer provayderning kalit sahifasini ochadi. Kalit yarating, qo'ying, Enter bosing. The Atlas kalitni saqlashdan oldin tekshiradi.
- **Ollama, OmniRoute**: lokal, kalit kerak emas. The Atlas server ishlayotganini tekshiradi.

## Kalitlarni terminaldan boshqarish

```bash
atlas keys add groq              # asks for the key, typed hidden
atlas keys add groq gsk_...      # or pass it (it stays in your shell history)
atlas keys list                  # stored keys, masked
atlas keys rm groq               # remove a key
atlas providers                  # every provider: ready, no key, or local
```

`atlas doctor` har bir ulangan provayderni tekshirib, javob vaqti va modellar sonini ko'rsatadi.

## Muhit o'zgaruvchilari

Agar provayder uchun kalit saqlanmagan bo'lsa, The Atlas yuqoridagi jadvaldagi o'zgaruvchini o'qiydi. Saqlangan kalit doim ustun turadi.

```bash
export GROQ_API_KEY=gsk_...
atlas
```

## Lokal modellar

**Ollama**: uni [ollama.com](https://ollama.com/download) dan o'rnating, model yuklab oling (`ollama pull llama3.2`) va ishlab turgan holda qoldiring. The Atlas `http://localhost:11434/v1` ga ulanadi.

**OmniRoute**: ko'plab akkauntlar va bepul tariflarni birlashtiradigan lokal shlyuz. `atlas omniroute` ni ishga tushiring. Batafsil: [OmniRoute](/guides/omniroute/).

Auto rejimda ishlamayotgan lokal server jimgina o'tkazib yuboriladi.

<Aside type="caution">
Kalitlar `~/.the-atlas/config.json` da oddiy matn ko'rinishida saqlanadi (macOS va Linux'da fayl huquqi 600). The Atlas har bir kalitni faqat o'z provayderiga yuboradi. Faylni hech kimga bermang, bepul tarif kalitlarini sotmang va ulashmang.
</Aside>
