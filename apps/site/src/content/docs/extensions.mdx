## MCP shablonlari

`atlas mcp add <preset>` bilan qo'shing:

| Shablon | Agentga nima beradi |
|---|---|
| `filesystem` | Joriy papka bilan cheklangan fayllarga kirish |
| `github` | GitHub repozitoriylari, issue va pull request'lar (token kerak) |
| `browser` | Playwright boshqaradigan brauzer |
| `memory` | Doimiy bilimlar grafi |
| `sequential-thinking` | Bosqichma-bosqich fikrlash vositasi |
| `sqlite` | SQLite ma'lumotlar bazasi fayli |
| `postgres` | PostgreSQL ma'lumotlar bazasi |
| `gdrive` | Google Drive |

Boshqa har qanday server: `atlas mcp add <name> -- <command>` yoki `atlas mcp add <name> --url <url>`. Claude Desktop'da ishlatayotgan serverlaringiz: `atlas mcp import claude`.

Har bir MCP vosita chaqiruvi ruxsatingizni so'raydi.

## Agentlar katalogi

`atlas agents` 47 ta agentdan iborat qidiriladigan ro'yxatni ochadi, jumladan Claude Code, OpenAI Codex, Gemini CLI, GitHub Copilot, Aider, OpenCode, Goose va Ollama. Birini tanlang: The Atlas kerak bo'lsa uni o'rnatadi va yangi oynada ochadi. `Tab` bilan (yoki `atlas run <agent> --free`) agent Atlas bepul modellaringizda ishlaydi.
