## Chat input

| Key | Action |
|---|---|
| `Enter` | Send the message, or run the selected `/command` |
| `↑` `↓` | Previous and next sent messages |
| `Esc` | While answering: stop. Otherwise: clear the input and cancel an armed `/compare` |
| `Tab` | Complete the selected `/command` or `@path` |
| `ctrl+r` | Record voice |
| `ctrl+c` | Quit |
| `/` | Open the command menu |
| `@` | Attach a file, image or folder; opens path suggestions |

While the `/` or `@` menu is open, `↑` `↓` move in the menu instead of the history.

## Lists and pickers

Model picker, connect wizard, history, limit menu.

| Key | Action |
|---|---|
| Type | Filter |
| `↑` `↓` | Move |
| `PgUp` `PgDn` | Move by a page |
| `Backspace` | Delete a filter character |
| `Enter` | Select |
| `Esc` | Back or cancel |

## Agents picker

Same as lists, plus:

| Key | Action |
|---|---|
| `Tab` | Toggle "run on Atlas free models" |

## OpenRouter sign-in

| Key | Action |
|---|---|
| `k` | Paste a key instead of the browser sign-in |
| `Esc` | Cancel |

## Agent approvals

| Key | Action |
|---|---|
| `↑` `↓` | Choose Yes / Yes, don't ask again / No |
| `Enter` | Confirm |
| `Esc` | No |

`Esc` while the agent is working stops it.

## Compare

| Key | Action |
|---|---|
| `←` `→` | Choose an answer |
| `Enter` | Keep it |
| `Esc` | Keep none |

## Voice

| Key | Action |
|---|---|
| `Enter` | Stop recording and transcribe |
| `Esc` | Cancel |
