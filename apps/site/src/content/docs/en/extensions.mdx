## MCP presets

Add one with `atlas mcp add <preset>`:

| Preset | What it gives the agent |
|---|---|
| `filesystem` | File access, limited to the current folder |
| `github` | GitHub repositories, issues and pull requests (needs a token) |
| `browser` | A Playwright-controlled browser |
| `memory` | A persistent knowledge graph |
| `sequential-thinking` | Step-by-step reasoning tool |
| `sqlite` | A SQLite database file |
| `postgres` | A PostgreSQL database |
| `gdrive` | Google Drive |

Any other server: `atlas mcp add <name> -- <command>` or `atlas mcp add <name> --url <url>`. Servers you already use in Claude Desktop: `atlas mcp import claude`.

Every MCP tool call asks for your approval.

## Agent catalog

`atlas agents` opens a searchable list of 47 agents, including Claude Code, OpenAI Codex, Gemini CLI, GitHub Copilot, Aider, OpenCode, Goose and Ollama. Pick one and The Atlas installs it if needed and opens it in a new window. With `Tab` (or `atlas run <agent> --free`) the agent runs on your Atlas free models.
