## The connect wizard

```bash
atlas connect            # pick from a list
atlas connect groq       # go straight to one provider
```

In the chat, use `/connect` or `/connect groq`.

- **OpenRouter**: one-click sign-in. The browser opens OpenRouter, you approve, and your own key returns to the terminal by itself. Press `k` to paste a key instead.
- **Other cloud providers**: the browser opens the provider's key page. Create a key, paste it, press Enter. The Atlas checks the key before saving it.
- **Ollama, OmniRoute**: local, no key. The Atlas checks that the server is running.

## Manage keys from the shell

```bash
atlas keys add groq              # asks for the key, typed hidden
atlas keys add groq gsk_...      # or pass it (it stays in your shell history)
atlas keys list                  # stored keys, masked
atlas keys rm groq               # remove a key
atlas providers                  # every provider: ready, no key, or local
```

`atlas doctor` pings every connected provider and shows the response time and model count.

## Environment variables

If no key is stored for a provider, The Atlas reads the variable from the table above. A stored key always wins.

```bash
export GROQ_API_KEY=gsk_...
atlas
```

## Local models

**Ollama**: install it from [ollama.com](https://ollama.com/download), pull a model (`ollama pull llama3.2`), keep it running. The Atlas talks to `http://localhost:11434/v1`.

**OmniRoute**: a local gateway that pools many accounts and free tiers. Run `atlas omniroute`. See [OmniRoute](/en/guides/omniroute/).

In auto mode a local server that is not running is skipped silently.

<Aside type="caution">
Keys are stored in plain text in `~/.the-atlas/config.json` (file mode 600 on macOS and Linux). The Atlas sends each key only to its own provider. Do not share the file, and do not resell or share free-tier keys.
</Aside>
