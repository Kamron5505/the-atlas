## Пресеты MCP

Добавьте через `atlas mcp add <preset>`:

| Пресет | Что получает агент |
|---|---|
| `filesystem` | Доступ к файлам, только в текущей папке |
| `github` | Репозитории, issues и pull requests GitHub (нужен токен) |
| `browser` | Браузер под управлением Playwright |
| `memory` | Постоянный граф знаний |
| `sequential-thinking` | Инструмент пошаговых рассуждений |
| `sqlite` | Файл базы данных SQLite |
| `postgres` | База данных PostgreSQL |
| `gdrive` | Google Drive |

Любой другой сервер: `atlas mcp add <name> -- <command>` или `atlas mcp add <name> --url <url>`. Серверы, которые вы уже используете в Claude Desktop: `atlas mcp import claude`.

Каждый вызов инструмента MCP требует вашего одобрения.

## Каталог агентов

`atlas agents` открывает список из 47 агентов с поиском, среди них Claude Code, OpenAI Codex, Gemini CLI, GitHub Copilot, Aider, OpenCode, Goose и Ollama. Выберите агента, и The Atlas при необходимости установит его и откроет в новом окне. С `Tab` (или `atlas run <agent> --free`) агент работает на ваших бесплатных моделях Atlas.
