`atlas --help` и `atlas <command> --help` выводят ту же информацию. Глобальные опции: `-v, --version`, `-h, --help`.

## Чат и ответы

### `atlas chat`

Интерактивный чат. Это команда по умолчанию, поэтому `atlas` без аргументов запускает её.

| Опция | Описание |
|---|---|
| `-p, --provider <id>` | ID провайдера или `auto` |
| `-m, --model <model>` | ID модели (при фиксированном провайдере) |
| `-c, --continue` | Продолжить последний чат в этой папке |

Нужен интерактивный терминал; в скриптах используйте `atlas ask`.

### `atlas ask [prompt...]`

Разовый ответ в stdout. Данные из stdin (pipe) добавляются к запросу как контекст.

| Опция | Описание |
|---|---|
| `-p, --provider <id>` | ID провайдера или `auto` |
| `-m, --model <model>` | ID модели |
| `-s, --system <text>` | Системный промпт |

```bash
atlas ask "explain this error" < build.log
git diff | atlas ask "write a commit message"
```

Сообщения о переключении идут в stderr, поэтому в stdout только ответ.

### `atlas agent <task...>`

[Режим агента](/ru/guides/agent-mode/): ИИ читает и правит файлы и запускает команды в текущей папке, спрашивая перед изменениями.

| Опция | Описание |
|---|---|
| `-p, --provider <id>` | ID провайдера или `auto` |
| `-m, --model <model>` | ID модели |

Завершается с кодом 1, если агент не справился.

### `atlas voice`

Записать один раз и напечатать распознанный текст. См. [Голосовой ввод](/ru/guides/voice/).

| Опция | Описание |
|---|---|
| `-d, --device <name>` | Имя или номер микрофона (см. `atlas voice devices`) |
| `-s, --seconds <n>` | Максимальная длина записи, по умолчанию `120` |
| `-l, --lang <lang>` | Подсказка языка речи: `uz`, `ru` или `en` |

| Подкоманда | Описание |
|---|---|
| `atlas voice devices` | Список микрофонов; сохранённый отмечен |
| `atlas voice device <name\|index>` | Запомнить микрофон: номер из списка, имя или `auto` |

## Провайдеры и ключи

### `atlas connect [provider]`

Мастер подключения: выберите ИИ, откроется браузер, вставьте ключ, он будет проверен. OpenRouter использует вход через браузер в один клик.

### `atlas keys`

| Подкоманда | Описание |
|---|---|
| `atlas keys add <provider> [key]` | Добавить или заменить ключ. Без `key` ввод будет скрытым |
| `atlas keys list` | Показать сохранённые ключи, замаскированы |
| `atlas keys rm <provider>` | Удалить ключ |

### `atlas providers`

Список всех провайдеров со статусом (готов, нет ключа, локальный), тарифом и страницей ключей.

### `atlas models [provider]`

Актуальный список моделей провайдера. Провайдер по умолчанию: `openrouter`.

| Опция | Описание |
|---|---|
| `-f, --free` | Только бесплатные модели |
| `--json` | Вывод в JSON |

### `atlas use <provider> [model]`

Задать провайдера по умолчанию (`auto` для цепочки переключения) и, при желании, его модель по умолчанию.

```bash
atlas use auto
atlas use groq llama-3.3-70b-versatile
```

### `atlas omniroute`

Установить, запустить и подключить локальный шлюз [OmniRoute](/ru/guides/omniroute/).

| Опция | Описание |
|---|---|
| `--url <url>` | Использовать удалённый OmniRoute, например `https://gw.example.com/v1` |
| `--key <key>` | API-ключ для удалённого OmniRoute |

### `atlas serve`

Локальный OpenAI-совместимый endpoint с переключением бесплатных моделей. См. [Локальный прокси](/ru/guides/serve/).

| Опция | Описание |
|---|---|
| `--port <n>` | Порт, по умолчанию `4141` |

## Агенты

### `atlas agents`

Выбрать, установить и запустить AI CLI агентов. См. [Запуск ИИ-агентов](/ru/guides/agents/).

| Опция | Описание |
|---|---|
| `-l, --list` | Напечатать каталог |
| `-f, --free` | Только бесплатные агенты |
| `-i, --installed` | Только установленные агенты |

### `atlas run <agent> [args...]`

Запустить агента по имени или команде; установит, если его нет. Дополнительные `args` передаются агенту.

| Опция | Описание |
|---|---|
| `--free` | Запустить агента через бесплатные модели Atlas |
| `-w, --window` | Открыть в новом окне терминала |
| `-y, --yes` | Установить без вопросов |

### `atlas install <agent>`

Установить агента.

| Опция | Описание |
|---|---|
| `-y, --yes` | Не спрашивать |

## MCP

### `atlas mcp`

Управление [MCP-серверами](/ru/guides/mcp/) (внешние инструменты для режима агента).

| Подкоманда | Описание |
|---|---|
| `atlas mcp list` | Серверы, их статус и число инструментов |
| `atlas mcp add <name> [command...]` | Добавить сервер: имя пресета, `--url <url>` или `-- <command> [args...]` |
| `atlas mcp remove <name>` | Удалить сервер (псевдоним `rm`) |
| `atlas mcp enable <name>` | Включить сервер |
| `atlas mcp disable <name>` | Выключить сервер, не удаляя |
| `atlas mcp tools <name>` | Подключиться к серверу и показать его инструменты |
| `atlas mcp import <source>` | Импортировать серверы из другого приложения (`claude` = Claude Desktop) |

Опции `atlas mcp add`:

| Опция | Описание |
|---|---|
| `--url <url>` | URL удалённого сервера (Streamable HTTP или SSE) |
| `-e, --env <pairs...>` | Переменные окружения `KEY=VALUE` для локального сервера |
| `-H, --header <pairs...>` | HTTP-заголовки `KEY=VALUE` для удалённого сервера |
| `--cwd <dir>` | Рабочая папка для локального сервера |

## Прочее

### `atlas lang <lang>`

Задать язык интерфейса: `uz`, `ru` или `en`.

### `atlas statusline`

Напечатать строку состояния из JSON Claude Code, полученного через stdin. См. [Строка состояния](/ru/guides/status-line/).

| Опция | Описание |
|---|---|
| `--install <agent>` | Установить в настройки агента (поддерживается: `claude`) |
| `-y, --yes` | Не спрашивать перед изменением настроек |

### `atlas doctor`

Проверить окружение (Node, npm, git, bash, Python, путь к настройкам), показать, что определено о терминале, и пропинговать каждого подключённого провайдера.

### `atlas help [command]`

Справка по команде.
