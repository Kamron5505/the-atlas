## v0.1.0 (не выпущен)

Первый релиз.

### Чат

- Интерактивный чат (`atlas`) с потоковыми ответами в Markdown, неоново-синим интерфейсом и печатающимся логотипом ATLAS.
- Меню слэш-команд, история ввода `↑` `↓`, `Esc` останавливает ответ.
- Вложения `@file`: текстовые файлы, изображения и списки содержимого папок.
- Сохранённые чаты: `/history`, `/resume`, `atlas -c`, `/export` в Markdown.
- `/compare`: спросить 2 или 3 ИИ сразу и оставить лучший ответ.
- Строка состояния: репозиторий, ветка, заполненность контекста, стоимость, изменённые строки, модель и остаток бесплатных запросов.
- Интерфейс на узбекском (по умолчанию), русском и английском: `/lang`, `atlas lang`.
- Простой ASCII и упрощённые цвета для старых терминалов; без эмодзи в элементах интерфейса.

### Модели и провайдеры

- 12 провайдеров: OpenRouter, Gemini, Groq, Cerebras, Mistral, GitHub Models, NVIDIA NIM, SambaNova, OmniRoute, Ollama, OpenAI, Anthropic.
- Режим auto: переключается на другие бесплатные модели и провайдеров до первого токена; незапущенные локальные серверы молча пропускаются.
- Вход в OpenRouter в один клик (OAuth с PKCE); мастер подключения других провайдеров с проверкой ключа.
- Выбор модели, счётчик бесплатных лимитов и меню смены ИИ, когда лимит исчерпан.
- `atlas omniroute` устанавливает, запускает и подключает шлюз OmniRoute.
- `atlas ask` для разовых ответов, удобных для pipe.
- `atlas serve`: локальный OpenAI-совместимый endpoint с переключением.

### Агенты и инструменты

- Режим агента (`atlas agent`, `/agent`): чтение, поиск, правка и запуск команд в проекте, с одобрением каждого изменения, путями только внутри проекта и закрытыми секретными файлами.
- MCP-серверы: пресеты, свои локальные и удалённые серверы, `atlas mcp import claude`; каждый вызов инструмента MCP требует одобрения.
- Голосовой ввод через `ctrl+r` и `atlas voice` (ffmpeg + Groq Whisper).
- Запуск 47 AI CLI агентов (`atlas agents`, `atlas run`): установка на Windows, macOS и Linux, открытие агентов в новом окне терминала, `--free` запускает их на бесплатных моделях Atlas.
- `atlas statusline --install claude` ставит строку состояния Atlas в Claude Code.
- `atlas doctor` проверяет окружение, терминал и провайдеров.

### Исправления перед релизом

- Windows: агенты, установленные через npm, не запускались (`ENOENT`); теперь используются только обёртки `.exe`, `.cmd` и `.bat`.
- Бесплатные модели OpenRouter, которые перестали быть бесплатными (404) или были заняты (429), больше не обрывают ответ; пробуются другие бесплатные модели.
- Одна занятая бесплатная модель больше не помечает весь провайдер как исчерпавший квоту.
- Модели отвечают как Atlas, а не называют исходную модель.
- При выходе экран очищается, как `cls` (`ATLAS_KEEP_SCREEN=1` его сохраняет).
