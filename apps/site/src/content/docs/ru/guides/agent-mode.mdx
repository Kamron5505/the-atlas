В режиме агента ИИ работает с проектом в текущей папке: читает файлы, ищет, правит и запускает команды, пока задача не будет выполнена.

```bash
atlas agent "add unit tests for src/date.ts"
atlas agent -p groq "fix the failing lint errors"
```

В чате:

```text
/agent rename the config option "verbose" to "debug" everywhere
```

Из чата агент видит весь разговор до этого момента. Режиму агента нужен интерактивный терминал, потому что он спрашивает одобрения.

## Инструменты

| Инструмент | Что делает | Спрашивает |
|---|---|---|
| `read_file` | Читает текстовый файл (до 2000 строк за вызов) | нет |
| `list_dir` | Показывает содержимое папки | нет |
| `search` | Поиск по регулярному выражению в файлах (без `node_modules`, `.git`, `dist`) | нет |
| `write_file` | Создаёт или перезаписывает файл | **да** |
| `edit_file` | Заменяет точный текст в файле | **да** |
| `run_command` | Запускает команду оболочки в папке проекта | **да** |
| Инструменты MCP | Инструменты ваших [MCP-серверов](/ru/guides/mcp/) | **да, всегда** |

## Одобрение

Перед каждым изменением вы видите превью: diff для правок, полную строку команды для `run_command`. Затем выберите:

| Ответ | Результат |
|---|---|
| **Да** | Выполнить этот вызов |
| **Да, больше не спрашивать в этой сессии** | Выполнить и разрешать этот инструмент без вопросов до конца работы агента |
| **Нет, сделай по-другому** | Пропустить вызов; ИИ узнаёт, что вы отказали |

`↑` `↓` выбирают, `Enter` подтверждает, `Esc` значит «Нет». `Esc` во время работы агента останавливает его.

В конце выводится итог: сколько шагов сделано и какие файлы изменены. Агент останавливается после 25 шагов; при необходимости попросите его продолжить.

## Безопасность

- **Только проект.** Файловые инструменты разрешают каждый путь внутри папки, где вы запустили агента. Пути снаружи, в том числе через символические ссылки, отклоняются.
- **Секретные файлы закрыты.** Агент не может читать или писать `.env` и `.env.*`, `*.pem`, `*.key`, `*.p12`, `*.pfx`, SSH-ключи (`id_rsa`, `id_ed25519` и похожие), всё в `.ssh/` или `.aws/`, `~/.the-atlas/config.json` и `~/.claude/.credentials.json`.
- **Команды.** `run_command` использует Windows PowerShell 5.1 на Windows и bash на других системах. Таймаут по умолчанию 2 минуты (максимум 10 минут); команда завершается, когда вы останавливаете агента. Вывод обрезается, чтобы контекст оставался небольшим.

<Aside type="caution">
`run_command` и инструменты MCP могут делать всё, что может ваш пользователь. Правила путей выше относятся к встроенным файловым инструментам, а не к командам оболочки. Читайте каждую команду перед одобрением и для `run_command` выбирайте **Да**, а не **Да, больше не спрашивать**. Используйте git, чтобы проверять и откатывать изменения.
</Aside>

## Выбор модели

Режиму агента нужна модель с поддержкой вызова инструментов (tool calling). В режиме auto, если модель отклоняет инструменты, The Atlas переходит к следующей. Чтобы закрепить модель:

```bash
atlas agent -p openrouter -m openrouter/free "..."
```
