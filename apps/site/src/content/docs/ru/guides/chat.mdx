Чат запускается командой `atlas` (то же, что `atlas chat`). В шапке видно, какие ИИ подключены и какая модель выбрана.

```bash
atlas                          # новый чат
atlas -c                       # продолжить последний чат в этой папке
atlas chat -p groq             # использовать одного провайдера
atlas chat -p openrouter -m openrouter/free
```

## Слэш-команды

Введите `/`, чтобы открыть меню команд. Продолжайте печатать для фильтра, `↑` `↓` для перемещения, `Tab` для дополнения, `Enter` для запуска.

Самые нужные:

| Команда | Что делает |
|---|---|
| `/connect` | Подключить ИИ |
| `/model` | Выбрать модель; `/model groq/llama-3.3-70b-versatile` задаёт её сразу |
| `/provider auto` | Вернуть автоматическое переключение между подключёнными ИИ |
| `/clear` | Начать новый разговор |
| `/help` | Все команды и клавиши |

Полный список: [Слэш-команды](/ru/reference/slash-commands/).

## Клавиши в чате

| Клавиша | Действие |
|---|---|
| `Enter` | Отправить |
| `↑` `↓` | Предыдущее и следующее отправленное сообщение (когда меню закрыто) |
| `Esc` | Остановить ответ, пока он идёт; иначе очистить поле ввода |
| `Tab` | Дополнить `/команду` или `@путь` |
| `ctrl+r` | [Голосовой ввод](/ru/guides/voice/) |
| `ctrl+c` | Выйти |

Если остановить ответ, уже полученная часть остаётся в чате с пометкой «остановлено».

## Файлы и изображения через @

Поставьте `@путь` в любом месте сообщения. Когда вы вводите `@`, меню предлагает файлы и папки; `Tab` дополняет.

```text
› @src/app.ts @package.json why does the build fail?
› @"docs/my notes.md" summarize
› @screenshot.png what is wrong in this UI?
› @src/ what is in this folder?
```

| Что вы прикладываете | Что получает ИИ | Лимит |
|---|---|---|
| Текстовый файл | Содержимое файла | 256 KB |
| Изображение (`.png` `.jpg` `.jpeg` `.webp` `.gif`) | Изображение | 5 MB |
| Папка | Список её содержимого (до 200 элементов; без `node_modules`, `.git`, `dist` и похожих) | |

Пути считаются от папки, где вы запустили `atlas`. Пути с пробелами берите в кавычки. Бинарные файлы, несуществующие файлы и файлы больше лимита не прикладываются; чат пишет причину.

<Aside>
Для изображений нужна модель, которая принимает изображения. Если выбранная модель не умеет, выберите другую через `/model`.
</Aside>

## Сохранённые чаты

Каждый чат хотя бы с одним сообщением автоматически сохраняется в `~/.the-atlas/sessions/`.

| Команда | Что делает |
|---|---|
| `/history` | Выбрать любой сохранённый чат и продолжить его |
| `/resume` | Продолжить последний чат, начатый в этой папке |
| `/export` | Сохранить чат в Markdown в текущей папке (`atlas-chat-<id>.md`) |
| `/export notes.md` | Сохранить под своим именем |
| `/clear` | Начать новый чат (старый остаётся в истории) |

Из оболочки `atlas -c` открывает последний чат текущей папки.

## Строка состояния

Строка под полем ввода показывает: репозиторий, ветку git, заполненность контекстного окна, примерную стоимость, незакоммиченные строки `+добавлено -удалено` и модель, которая ответила, с остатком бесплатных запросов. См. [Строка состояния](/ru/guides/status-line/).
