Одна строка со всем важным во время работы:

```text
the-atlas | 🌿 (main) | 🟢 ████░░░░░░░░░░░░░░░░ 12% | $0.00 | +10 -2 | 🤖 groq/llama-3.3-70b-versatile 980/1000
```

| Часть | Значение |
|---|---|
| `the-atlas` | Имя репозитория (или папки) |
| `(main)` | Текущая ветка git |
| Полоса и `12%` | Насколько заполнено контекстное окно модели; от зелёного к красному |
| `$0.00` | Примерная стоимость сессии (бесплатные модели стоят 0) |
| `+10 -2` | Незакоммиченные добавленные и удалённые строки (`git diff HEAD`) |
| Модель | Модель, которая ответила последней, и остаток её бесплатных запросов |

Где эмодзи не рисуются, используются текстовые метки: `br:`, `OK` / `MID` / `HOT` / `MAX`, `ai:`, и `#` `.` для полосы.

## В чате Atlas

Строка состояния всегда включена и стоит под полем ввода. Пока вы вводите `/` или `@`, на её месте показывается меню.

## В Claude Code

Claude Code может показывать ту же строку внизу экрана:

```bash
atlas statusline --install claude
```

The Atlas показывает изменение, просит подтверждения (`-y` пропускает вопрос), делает резервную копию файла настроек и задаёт:

```json
{
  "statusLine": { "type": "command", "command": "atlas statusline", "padding": 0 }
}
```

в `~/.claude/settings.json` (или `$CLAUDE_CONFIG_DIR/settings.json`). Перезапустите Claude Code, чтобы увидеть строку. Если строка состояния у вас уже была, The Atlas покажет её перед заменой; она останется в резервной копии.

В Claude Code строка показывает модель Claude, стоимость сессии, изменённые строки и заполненность контекста; всё берётся из JSON, который отправляет Claude Code.

<Aside>
API строки состояния есть только у Claude Code, поэтому `claude` единственное значение, которое принимает `--install`.
</Aside>

## Удаление

Удалите запись `statusLine` из `~/.claude/settings.json` или восстановите резервную копию (`settings.json.atlas-backup-<date>`) рядом с ним.

## Проверка вручную

`atlas statusline` читает JSON Claude Code из stdin и печатает одну строку:

```bash
echo '{"model":{"display_name":"Opus"},"cost":{"total_cost_usd":0.42}}' | atlas statusline
```
