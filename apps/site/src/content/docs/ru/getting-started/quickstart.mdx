<Steps>

1. **Запустите The Atlas** в любой папке:

   ```bash
   atlas
   ```

   Логотип ATLAS печатается по буквам, затем открывается чат. Интерфейс сначала на узбекском; шаг 4 переключает его на русский.

2. **Подключите ИИ.** При первом запуске ни один ИИ не подключён, поэтому окно подключения откроется само. Позже его можно открыть командой `/connect`.

   Выберите **OpenRouter**. Браузер откроет страницу входа OpenRouter. Войдите и подтвердите; ключ сам вернётся в терминал и будет проверен. Нажмите `k`, чтобы вставить ключ вручную, или `Esc` для отмены.

   Другие провайдеры открывают в браузере страницу ключей; вставьте ключ и нажмите Enter. См. [Подключение провайдеров](/ru/guides/connect/).

3. **Спросите.** Введите вопрос и нажмите Enter:

   ```text
   › explain what a monorepo is in two sentences
   ```

   Ответ приходит потоком. Пока он идёт, `Esc` его останавливает. Строка состояния под полем ввода показывает модель, которая ответила, и сколько бесплатных запросов осталось.

4. **Смените язык** интерфейса (`uz`, `ru` или `en`):

   ```text
   /lang ru
   ```

   Или из оболочки: `atlas lang ru`. Сам ИИ отвечает на том языке, на котором вы пишете.

</Steps>

## Что попробовать дальше

| Введите | Что делает |
|---|---|
| `/` | Показать все слэш-команды |
| `/model` | Выбрать модель из всех подключённых ИИ |
| `@src/app.ts what does this do?` | Приложить файл к вопросу |
| `/compare` | Спросить 2 или 3 ИИ сразу |
| `/agent add a README` | ИИ правит файлы и запускает команды с вашего одобрения |
| `/agents` | Открыть один из 47 AI CLI для кода в новом окне |
| `ctrl+r` | Говорить вместо набора текста |

## Без интерфейса чата

```bash
atlas ask "what is the capital of Uzbekistan?"
git diff | atlas ask "review this change"
```

`atlas ask` печатает ответ в stdout; входные данные из pipe добавляются к вопросу.

<Aside>
Ключи хранятся только на вашем компьютере, в `~/.the-atlas/config.json`. The Atlas отправляет каждый ключ только его провайдеру.
</Aside>
