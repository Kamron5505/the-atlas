## Инструменты

| Инструмент | Зачем | Ссылка |
|---|---|---|
| Node.js 22+ | Запускает The Atlas | [nodejs.org/en/download](https://nodejs.org/en/download) |
| Windows Terminal | Полный цвет и иконки на Windows | [aka.ms/terminal](https://aka.ms/terminal) |
| ffmpeg | Записывает звук для голосового ввода | [ffmpeg.org/download.html](https://ffmpeg.org/download.html) |
| Ollama | Локальные модели, без ключа | [ollama.com/download](https://ollama.com/download) |
| OmniRoute | Локальный шлюз, объединяет аккаунты и бесплатные тарифы | [github.com/diegosouzapw/OmniRoute](https://github.com/diegosouzapw/OmniRoute) |
| Git for Windows | Git Bash, нужен некоторым установщикам агентов | [git-scm.com/downloads](https://git-scm.com/downloads) |
| Model Context Protocol | Стандарт MCP и список серверов | [modelcontextprotocol.io](https://modelcontextprotocol.io) |
